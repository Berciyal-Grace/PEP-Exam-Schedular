EXAM COMPANION — FINAL UI
=========================

This version includes:
- Login page shown first
- Uploaded exam illustration used as the application logo/visual
- Larger typography and more readable spacing
- Exam setup screen
- Live countdown
- Calm / Focus / Final Stretch mood system
- Motivational quote API with fallback quotes
- Study timeline
- Interactive completion checkboxes and progress percentage
- Change Exam button
- No refresh buttons
- Responsive desktop/tablet/mobile design

FILES
-----
index.html    Page structure and screens
style.css     Full visual design and responsive styling
script.js     Login flow, countdown, mood, quote API and study plan
exam_logo.jpg Uploaded illustration used by the UI

RUN
---
Open index.html directly, or use VS Code + Live Server.

NOTE
----
The login is a frontend/demo login only. It validates that the student enters a name, email and password; it does not connect to a backend or authenticate against a database.
